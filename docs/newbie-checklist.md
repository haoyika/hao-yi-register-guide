# 号易代理注册前核对清单

> 注册号易分销系统前，逐项过一遍。

## 注册前

- [ ] 认准官方入口：[haoyi.online/register-agent](https://haoyi.online/register-agent)，官方邀请码 **663998**
- [ ] 准备本人实名手机号（一个身份证只能实名一个账号）
- [ ] 了解结算模式：秒返（约 3-5 天到账）与次月返（次月底 25-30 号）
- [ ] 想好自己的流量类型，决定首个主推项目

## 注册时

- [ ] 从官方链接进入会自动带入邀请码 663998；手动填写时逐位核对
- [ ] 邀请码提交后绑定关系通常不可更改
- [ ] 阅读并同意《服务协议》《隐私政策》

## 注册后

- [ ] **完成实名认证**（不实名看不到也提不了佣金）
- [ ] 熟悉后台三大模块：商品管理（选品）、订单管理（查单）、财务管理（佣金提现）
- [ ] 挑 1~2 款主推套餐（优先有大流量、有专属素材的），生成推广链接
- [ ] 自己先走一遍下单流程测试链接
- [ ] 首单佣金到账后，绑定收款方式完成提现闭环

## 推广红线

诱导下单、代充报销、二次包装、废单转单、涉诈订单——都会被扣佣或封号，如实介绍套餐是底线。
